## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

## Description

Project Management System (PMS) is a web-based application developed to simplify and organize project-related activities within an organization. The system is designed to provide a centralized platform where users can manage projects, tasks, team members, project progress, and related information. The main objective of the project is to reduce manual work, improve project visibility, and make it easier for managers and team members to track project activities from a single system.
Role & Contributions: My major responsibilities included understanding the Laravel project architecture, working with controllers, models, routes, views, and database operations. I analyzed the existing codebase to understand how different modules were connected and how data was transferred between the frontend, backend, and database.
Technical Implementation: The application follows the MVC (Model-View-Controller) architecture provided by Laravel. Models are responsible for interacting with database tables, controllers handle application logic and requests, and views are responsible for presenting information to users.
Problem Solving and Debugging: One of the challenging aspects of the project was working with an existing codebase and understanding functionality that had already been implemented. Instead of assuming how the application worked, I followed the execution flow through routes, controllers, models, views, and database queries.
Learning Outcomes: I improved my understanding of PHP and backend development, particularly in areas such as routing, controllers, models, database operations, and CRUD functionality.
The project also strengthened my understanding of relational databases and MySQL. I learned how application data is structured in tables and how backend code interacts with the database.
Key Outcome: More importantly, the project provided practical experience in understanding a complete application flow—from a user's request, through Laravel routes and controllers, to database operations and back to the user interface. It improved my ability to analyze existing systems, implement functionality, troubleshoot problems, and work with commonly used development tools.
Duration: 180 days
Domain: Project Management / Enterprise Web Application
Tech Stack: Laravel, MySQL, JavaScript, Bootstrap
Team Size: Small development team
Complexity: Intermediate
Tools: vs code, xampp, git
Key Features:
1. Project creation and management
2. Project information management
3. Task management
4. Task assignment to team members
5. Task status tracking
6. Project progress monitoring
7. Database-driven project and task records
8. Backend CRUD operations
9. User and project-related data management
10. Integration between Laravel backend and MySQL database
