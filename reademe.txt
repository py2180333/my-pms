Laravel Project Setup Instructions

1. Create the .env file
   Copy the .env.example file and rename the copy to .env.

2. Configure the database
   Update the database settings in the .env file according to your local system:

   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=pms
   DB_USERNAME=root
   DB_PASSWORD=

   If your MySQL root user has a password, enter it after DB_PASSWORD=.

3. Install/update Composer dependencies
   Run:

   composer update

4. Generate the Laravel application key
   Run:

   php artisan key:generate

5. Import the MySQL database
   Import the provided MySQL (.sql) file into your MySQL server.
   Make sure the imported database name matches the DB_DATABASE value in the .env file (pms).

6. Start the Laravel development server
   Run:

   php artisan serve

7. Open the application
   After the server starts, open the URL shown in the terminal, usually:

   http://127.0.0.1:8000
